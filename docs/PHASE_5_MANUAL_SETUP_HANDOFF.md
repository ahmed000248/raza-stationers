## 2. Cloud Manual Resource Creation

Please create or configure the following three staging resources:

### A. Supabase Staging Database (Isolated Project)
1. Log into your **Supabase Dashboard**.
2. Create a new, separate project (do NOT use your production project `pqlmgqzpjjllhgalyhwz`).
3. Obtain your staging connection strings:
   * **Staging DATABASE_URL**: Connection-pooled string (usually port 6543 with `?pgbouncer=true` parameter).
   * **Staging DIRECT_URL**: Direct connection string (usually port 5432) for running DDL migrations.
4. *Security Warning*: Never commit these connection strings to Git or put them in public files.

### B. Docker Backend Host (NestJS Staging API)
1. Select a container hosting provider (e.g., **Render**, **Railway**, or **Fly.io**).
2. Connect your Git repository (`raza-stationers`) to the provider dashboard.
3. Configure the service:
   * **Build Target**: Dockerfile build (context: `./`, Dockerfile: `Dockerfile`).
   * **Environment Variables**:
     * `NODE_ENV=production`
     * `PORT=4000` (or the host-injected port variable)
     * `JWT_SECRET=your_staging_jwt_secret_minimum_32_characters`
     * `CORS_ORIGINS=https://your-vercel-staging-url.vercel.app` (comma-separated origins)
     * `DATABASE_URL` = *(inject staging pooled connection string)*
     * `DIRECT_URL` = *(inject staging direct connection string)*
4. Retrieve the public HTTPS endpoint URL of your deployed NestJS API (e.g., `https://raza-api-staging.up.railway.app`).

### C. Vercel Staging Frontend Projects
1. Log into your **Vercel Dashboard**.
2. Import the `raza-stationers` monorepo.
3. Setup **two** Vercel projects (one for customer storefront, one for admin panel):
   * **Project 1 (Customer Storefront)**:
     * Root directory: `apps/web`
     * Environment variables:
       * `NEXT_PUBLIC_API_URL` = *(your public NestJS staging API HTTPS URL)*
   * **Project 2 (Admin operations Panel)**:
     * Root directory: `apps/admin`
     * Environment variables:
       * `NEXT_PUBLIC_API_URL` = *(your public NestJS staging API HTTPS URL)*
4. Retrieve the Preview/Staging URLs generated by Vercel for these deployments.
